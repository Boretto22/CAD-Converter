# Privacidad y datos

La CLI no contiene telemetría, cuentas ni llamadas de red. Procesa los archivos autorizados y escribe la salida en el destino solicitado. Las bibliotecas se descargan durante la instalación mediante el gestor de paquetes del usuario.

El procesamiento con ChatGPT depende del entorno y de los controles de datos de la cuenta. Este documento describe el programa local, no modifica ni sustituye las condiciones de ChatGPT.

Las entregas conservan originales, metadatos de las fuentes, hashes y modelos. `modelo-original.json` puede contener rutas locales. Antes de compartir una entrega CAD, revisar derechos, datos personales, cajetines, rutas y metadatos. Compartir el software no requiere compartir los planos.

No existe servicio alojado ni mecanismo de retención remota operado por este proyecto. El usuario conserva el control de sus archivos locales. El programa no borra originales ni sobreescribe entregas anteriores. Las salidas parciales se identifican como tales.
